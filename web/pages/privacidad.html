Política de Privacidad

Última actualización: Septiembre 2026

1. Sobre TaskDAM

TaskDAM es una aplicación académica para consultar horarios y organizar tareas y exámenes. La conexión con Google Calendar es opcional y solo se inicia cuando el usuario la solicita.

2. Datos tratados

La app Flutter, tanto en web como en Android, utiliza Firebase Authentication y Cloud Firestore para las cuentas, tareas y recordatorios. Los datos se guardan bajo el identificador de la cuenta y las reglas de seguridad de Firestore limitan el acceso a los documentos de cada usuario.

3. Uso de datos de Google

Si eliges conectar Google Calendar desde la versión web, Google solicita los permisos calendar.events y userinfo.email. TaskDAM consulta el correo de Google únicamente para comprobar que coincide con el correo de tu cuenta de TaskDAM. El token de acceso se mantiene en la memoria de la página durante la sesión y no se guarda en Firebase.

Al guardar, editar o borrar una tarea con Calendar conectado, TaskDAM crea, actualiza o elimina el evento correspondiente en tu calendario principal. El evento contiene el tipo de apunte, la asignatura, su descripción y la fecha. TaskDAM no lee ni importa tu calendario completo. Si desconectas Google, los eventos ya creados permanecen en Calendar; puedes borrarlos allí. La conexión se puede revocar desde el botón de Google Calendar.

4. Servicios y conservación

Firebase presta la autenticación y el almacenamiento. Google recibe los datos necesarios para gestionar eventos solo si conectas Calendar. TaskDAM no vende datos ni los utiliza para publicidad. Los datos se conservan hasta que se borren desde la aplicación o el servicio correspondiente. Eliminar una cuenta de Firebase Authentication no elimina automáticamente sus documentos de Firestore; para solicitar la eliminación de los datos, utiliza el correo de asistencia publicado en la pantalla de consentimiento OAuth. La eliminación de una tarea borra el evento de Google cuando hay una conexión activa; de lo contrario, el evento debe borrarse en Google Calendar.

5. Tus opciones y solicitudes

Puedes editar o borrar tus tareas desde la aplicación, desconectar Google Calendar y revocar el permiso concedido. La aplicación no incluye actualmente una opción para eliminar la cuenta. Para solicitar la eliminación de la cuenta y sus tareas, utiliza el correo de asistencia publicado en la pantalla de consentimiento OAuth de TaskDAM. No envíes contraseñas ni datos de tus tareas por canales públicos.

6. Política de Google

El uso de información recibida de las API de Google cumple la Política de datos de usuario de los servicios API de Google, incluidos sus requisitos de uso limitado.
